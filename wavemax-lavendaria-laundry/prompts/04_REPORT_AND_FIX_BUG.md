# Report and Fix a Bug

Read `AGENT_START.md`, the active phase, bug index, prevention rules, loop policy, and engineering standard.

Locate the exact file/function/line. Trace trigger to failure. Explain the causal root. Connect downstream impact. Add a failing regression test when feasible. Apply the smallest approved fix. Verify the affected path and adjacent behavior. Add the strongest enforceable prevention and update bug memory. Stop after three evidence-driven attempts.
